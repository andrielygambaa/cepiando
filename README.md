# 📍 CEPiando — Cadastro Inteligente por CEP

✨ Um projeto web desenvolvido com **HTML, CSS e JavaScript puro** que automatiza o preenchimento de endereços por meio da consulta à **API ViaCEP**, tornando o cadastro mais rápido, prático e eficiente.

Neste projeto, o usuário informa um **CEP**, e o sistema busca automaticamente os dados correspondentes, preenchendo os campos de **rua, bairro, cidade e UF**, sem precisar recarregar a página.

---

# 🌐 Demonstração do Projeto

A aplicação funciona como um **formulário inteligente de cadastro**, que utiliza uma API externa para localizar informações de endereço a partir do CEP informado.

💡 Ao inserir um CEP válido, o sistema realiza uma consulta assíncrona e atualiza os campos do formulário automaticamente.

📍 Preenchimento automático do endereço  
⚡ Consulta de dados em tempo real  
💬 Mensagens amigáveis para orientar o usuário  
🛡️ Tratamento de erros para lidar com falhas na consulta ou CEPs inválidos

---

# 🧠 Conceitos Praticados

Este projeto permite desenvolver conhecimentos importantes sobre desenvolvimento web e integração com APIs:

🌐 **Consumo de API (ViaCEP)**  
Utilização de uma API externa para obter informações de endereço a partir do CEP.

⚡ **Requisições assíncronas com `fetch()`**  
Busca de dados sem bloquear a interface ou precisar recarregar a página.

📦 **Manipulação de JSON**  
Conversão e leitura dos dados retornados pela API para acessar as informações do endereço.

🧩 **Manipulação do DOM**  
Atualização dinâmica dos campos do formulário utilizando JavaScript.

🛡️ **Tratamento de erros com `try/catch`**  
Identificação e tratamento de falhas durante a consulta, proporcionando mensagens mais claras ao usuário.

⌨️ **Manipulação de formulários**  
Captura do CEP informado e preenchimento automático dos campos correspondentes.

# 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

💻 **HTML5**  
Estrutura do formulário de cadastro e organização dos campos de endereço.

🎨 **CSS3**  
Estilização da interface e apresentação visual do formulário.

⚡ **JavaScript puro (Vanilla JavaScript)**  
Responsável pela lógica da aplicação, pelas requisições assíncronas e pela atualização dinâmica da página.

🔗 **API ViaCEP**  
Serviço externo utilizado para consultar os dados de endereço com base no CEP informado.

---

# 🚀 Como Usar

1️⃣ Acesse o formulário do CEPiando.  
2️⃣ Digite o CEP desejado no campo indicado.  
3️⃣ O sistema consulta automaticamente a API ViaCEP.  
4️⃣ Os campos de rua, bairro, cidade e UF são preenchidos com os dados retornados.  
5️⃣ Caso ocorra algum problema, a aplicação apresenta uma mensagem amigável ao usuário.

📍 **Menos preenchimento manual, mais praticidade no cadastro!**
